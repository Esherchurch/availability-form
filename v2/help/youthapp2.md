# Youth Hub

The youth group's app, on a phone: the youth services, the songs, notes and news.

## Who can use it
- Young people in the youth group, with the access code a leader sent them. Enter it on **Youth access**.
- People on the church's youth teams, those teams' admins, and master admins.
- Anyone else sees **This page isn't for you**, with a link to enter an access code and a **Back to hub** button.

## Good to know
- A young person's phone never holds anyone's email address. **Email the plan** shows only for the youth team.
- Only youth services can be changed. Any other service shows as "(view only)".
