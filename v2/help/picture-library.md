# Picture library

This page holds pictures the church uses again and again, such as a club's or a regular service's picture. Events can use a picture from here, so every date and every copy shows the same one.

## Who can use it
- The church office, the bookings admins and master admins.
- Anyone else is told "This page is for the church office, the bookings admins and master admins."
- The picture library has to be switched on for the church. If it is off, the page says so.

## Add a picture
1. Under **Add a picture**, press **Choose a picture** and pick one.
2. The **Name** fills in from the file name. Change it to something clear.
3. Add **Tags** if you like, with commas between them.
4. Press **Add to the library**.

## Use a picture in an event
1. Open the event in What's On.
2. Press **Choose from library** and pick the picture.

## Rename a picture or change its tags
1. Find the picture on this page.
2. Change its **Name** or **Tags**.
3. Press **Save**.

## Replace a picture
1. Find the picture and press **Replace**.
2. Choose the new picture.
3. Every event using it now shows the new picture. The page says how many.

## Delete a picture
1. Find the picture and press **Delete**.
2. The page tells you how many events use it.
3. Press **Delete** again to be sure, or **Cancel**.
4. Events that used it show no picture until someone picks another.

## Good to know
- Each picture says how many events use it, or "Not used by any event".
- Replacing is better than deleting when you just want a fresh picture.

## Who to ask
- The church office.
- A master admin, if the library is switched off or you can't open the page.
