# Connect ChurchShow

This is where you connect a projection computer to the hub. Once it is connected, ChurchShow can read the service plan and the song words for the screens.

## Who can use it
- Team admins of the teams that run the screens and the music can open it. So can master admins.
- ChurchShow has to be switched on for the church. If it is off, the page says so. A master admin can turn it back on in Church settings.
- Anyone else is turned away.

## Connect a computer
1. Under **Make a pairing code**, choose the building in **Which building is the screen in?**
2. Type a name in **What shall we call this computer?**, for example "Main hall PC".
3. Press **Make pairing code**. A code shows, with how long it has left.
4. On the projection computer, open ChurchShow. Go to **Settings**, then **Connect to the hub**.
5. Type the code and press Connect.
6. Leave this page open until it says it has connected.

## See what is connected
1. **What is connected** lists every projection computer, with its building.
2. Each shows **On** or **Off**, and the date it was connected or disconnected.
3. Press **Refresh** to check again.

## Rename a computer
1. Press **Rename** on its row.
2. Type the new name and press **Save**.

## Connect a computer again
1. If a computer has lost its sign-in, press **Pair again** on its row.
2. A new code shows at the top. Type it into ChurchShow as above.

## Disconnect a computer
1. Press **Disconnect** on its row and say yes.
2. That one computer stops reading the hub straight away. The others stay connected.
3. Use this if a computer goes missing. Press **Pair again** to bring it back.

## Choose a computer's job (master admins)
1. Press **Job** on its row.
2. Tick **Main services**, and any **Lessons** groups it should show.
3. Press **Save the job**. It works straight away.

## Good to know
- A code lasts fifteen minutes and works only once. Nobody needs it afterwards.
- If there are no buildings yet, add one in Places first.
- Until a computer is connected, the screens would be empty on Sunday.
- Each computer has its own connection, so a building can have several.

## Who to ask
- Whoever looks after the screens.
- A master admin, if you cannot open the page or ChurchShow is switched off.
