What this does

ChurchShow reads the service plan and the song words from the hub. Until it is connected it cannot, so the screens would be empty on Sunday.

Each computer has its own connection, so a building can have several - the main hall PC and the Kids Church laptop, say. Disconnect switches that one computer off straight away and leaves the others alone - use it if a computer goes missing. Pair again makes a new code for the same computer, if it has lost its sign-in.
