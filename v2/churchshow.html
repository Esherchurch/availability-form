What this does

ChurchShow reads the service plan and the song words from the hub. Until it is connected it cannot, so the screens would be empty on Sunday.

One connection covers a building, not a computer, so the spare machine can use its own code without stopping the main one. Disconnect switches the whole building off straight away — use it if a computer goes missing, then connect again when it is back.
