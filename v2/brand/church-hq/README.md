# Church HQ brand kit

Open `index.html` for a visual overview.

| Folder | Contents |
|---|---|
| `svg/` | Master vector files. `logo-light` / `mark-light` for white backgrounds, `logo-dark` / `mark-dark` for slate or dark backgrounds, `app-icon` (rounded tile). Wordmark is outlined, so no font is needed. |
| `png/` | Ready-to-use images: logos at 1200px wide, marks and app icon at 512px. |
| `favicon/` | Website icons, `site.webmanifest` and `head-snippet.html`. The favicon has a heavier cross so it reads at 16px. |
| `brand.css` | Colour and font tokens. |

## Colours
- Slate `#2F4A48` – primary
- Teal `#5B9A8B` – secondary
- Lime `#9CC65A` – accent (the cross)
- Mint `#C9E3A6` – soft accent
- Paper `#F4F7F2` – off-white on dark

## Type
Plus Jakarta Sans (Google Fonts, free). Wordmark: "church" Regular 400 + "hq" SemiBold 600, tracking -3%.
On dark backgrounds use Light 300 + Medium 500 to correct for light-on-dark spread.

## Rules
- Give the logo clear space at least the width of the doorway on every side.
- Use the light version on white/light backgrounds and the dark version on slate.
- Don't recolour the cross, stretch the mark, or put the light version on dark backgrounds.
